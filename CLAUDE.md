# CLAUDE.md

Instructions for Claude when creating or editing news posts in this Hugo site.

## Site structure

```
content/
└── news/
    ├── 2026/
    │   └── 07/
    │       ├── post-slug/
    │       │   ├── index.md         # Post content & front matter
    │       │   ├── X8fK2pLm.jpg     # Featured image = FIRST image referenced in the post
    │       │   └── images/          # Additional gallery images (optional)
    │       │       ├── a9QwT7nR.webp
    │       │       ├── J4xMvP2k.png
    │       │       └── zN8rHy5L.jpg
    │       │
    │       ├── post-slug-2/
    │       │   ├── index.md
    │       │   ├── R7mKq2Xv.webp
    │       │   ├── images/
    │       │   └── videos/          # Videos, if any (see below)
    │       │
    │       └── _index.md            # Monthly section (auto-generated by Hugo, don't hand-edit)
    │
    └── _index.md                    # News section index (don't hand-edit)
```

- Posts live under `content/news/YYYY/MM/<slug>/`.
- Each post is a Page Bundle: an `index.md` plus its own media files sitting next to it.
- Featured image: the **first** image used in the post, stored directly in the post folder (root of the bundle), keeping whatever filename it came with (e.g. `X8fK2pLm.jpg`) — don't rename to `featured.jpg`.
- Any additional images go in an `images/` subfolder inside the post bundle.
- Any videos go in a `videos/` subfolder inside the post bundle.
- Never edit `_index.md` files — those are section pages, not posts.

## Creating a new post

Command:

```
hugo new content/news/YYYY/MM/<slug>/index.md
```

Where:
- `YYYY/MM` = year/month the post is published in.
- `<slug>` = URL-friendly slug for the post (see Slug rules below).

## Front matter

```toml
+++
date = 'YYYY-MM-DDT12:00:07+03:00'
draft = false
title = 'The quick brown fox jumps over the lazy dog'
slug = 'the-quick-brown-fox-jumps-over-the-lazy-dog'
+++
```

Rules:
- `date`: use the original publish date/time of the source post if known, in `+03:00` (Europe/Moscow) offset, format `YYYY-MM-DDT12:00:07+03:00`. If no time is known, default to `12:00:07`.
- `draft`: `false` once content and images are finalized; set to `true` if the post is a work-in-progress.
- `title`: derived from the post content — a short, natural-language summary/headline, not just the first sentence, unless the first sentence already works well as a title.
- `slug`: kebab-case, lowercase, ASCII, derived from the title (see rules below). Must match the folder name `<slug>`.

## Slug rules

- Lowercase, words separated by single hyphens (`-`).
- Strip punctuation; transliterate non-Latin scripts (e.g. Russian) to Latin rather than leaving Cyrillic in the slug, unless the user says otherwise.
- No leading/trailing hyphens, no double hyphens.
- Keep it reasonably short (aim for ≤ 8–10 words); trim filler words if the title is long.
- The folder name and the `slug` front-matter field must always match exactly.

## Input format: pasted VK posts

The user pastes VK post content directly in chat, in this shape:

```
Post content go here..
[7 д назад](https://vk.ru/wall62548391_4747)
```

- The last line is VK's own relative-timestamp link (e.g. `7 д назад` = "7 days ago"), linking to the original post.
- Treat that link's URL as the **source post URL** — use it to work out the actual publish date (relative to when the user pasted it) if no more precise date is available, and optionally keep it as a reference link at the end of the post body (e.g. `[Источник](https://vk.ru/wall62548391_4747)`), unless the user says not to.
- Strip the raw `[7 д назад](...)` line itself out of the final post body — it's VK chrome, not content.
- Everything above that line is the actual post text: clean it up into proper Markdown (paragraphs, lists, etc.) but don't alter meaning or add facts not present.

## Media handling

The user adds all images and video files manually themselves — Claude does not fetch, download, or place media files.

- Don't reference specific image/video filenames in the Markdown body, since Claude doesn't know what they'll be named — leave that to the user, or use placeholder comments like `<!-- image here -->` only if asked.
- Claude's job is limited to: front matter, slug/folder naming, and the cleaned-up post body text.

## Workflow for converting a pasted VK post into a Hugo post

1. Take the pasted post content; separate the post text from the trailing `[... назад](url)` line.
2. Determine the publish date from the source URL/relative timestamp if possible; otherwise ask the user or use the paste time. Use it for `date`.
3. Write a `title` summarizing the post.
4. Generate the `slug` from the title.
5. Create the bundle: `hugo new content/news/YYYY/MM/<slug>/index.md`.
6. Write the cleaned-up post body in Markdown under the front matter.
7. Set `draft = false` once the text is finalized (media will be added by the user afterward).

## Things NOT to do

- Don't rename source media filenames — Claude isn't handling media at all now.
- Don't put images loose in `content/news/YYYY/MM/` — they belong inside the specific post's bundle (handled manually by the user).
- Don't hand-edit `_index.md` files.
- Don't fabricate a date, title, or slug without checking the source content first.
- Don't leave the VK `[... назад](url)` chrome line in the final post body.
